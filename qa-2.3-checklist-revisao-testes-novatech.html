Checklist de Revisão — Testes de Integração

Framework: Vitest · Mocks: msw
Fixtures: tests/fixtures/ · Serviços: Azure AI Search, Azure OpenAI

Parte 1 — Verificações Rápidas Sim / Não · busca no arquivo · ~45 seg

  • Comentários // arrange, // act, // assert presentes no teste.
  • Nome do it segue should [comportamento] when [condição].
  • msw está importado no arquivo de teste.
  • Dados de entrada importados de tests/fixtures/ (não inline).
  • Ausência de strings genéricas: "test", "foo", "hello" como entrada.
  • toBeDefined() ou toBeTruthy() não são a única assertion.
  • Nenhuma chamada real de rede sem handler msw correspondente.
  • beforeEach / afterEach presente onde handlers são registrados.

Parte 2 — Verificações de Qualidade Requerem leitura · ~60 seg

  • Mock msw corresponde ao endpoint real que o módulo chama.
  • Assertions verificam contrato externo, não detalhe de implementação interna.
  • Dados de entrada fazem sentido no domínio de logística NovaTech.
  • Teste falha se a implementação estiver errada (não é trivialmente verde).
  • Não há estado compartilhado entre testes no mesmo arquivo.
  • Cenário de erro (4xx / 5xx) coberto além do caminho feliz.
  • Response mockada reflete a estrutura real da API Azure (campos, tipos).
